# 03: 轉盤拖動設定時只重畫有變的區塊

Status: resolved
Blocked by: None (can start immediately)

**What to build:** 轉盤頁在每次狀態變動時都整頁重畫。結果彈窗開著時，每次重畫都用二分法重找彈窗字級，每試一次就強制瀏覽器重排版面（約 7 到 10 次）；歷史紀錄也每次都重建。改成只有影響彈窗大小的資料（字型、結果彈窗大小比例、轉盤大小、結果文字）改變時才重算字級，歷史紀錄只在內容改變時才重建。

來源：效能審查（2026-11-15），轉盤第 2 項與歷史紀錄的小項。

- [x] 結果彈窗開著時拖動無關的設定，不重新計算彈窗字級
- [x] 改字型或結果彈窗大小時，已顯示的彈窗仍即時跟著更新；視窗大小改變時也正確
- [x] 歷史紀錄只在內容改變時重建，新的結果照常出現
- [x] 語言切換後所有文字仍正確

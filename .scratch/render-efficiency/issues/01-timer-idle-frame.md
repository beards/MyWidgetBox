# 01: 計時器閒置時跳過每幀的計算

Status: resolved
Blocked by: None (can start immediately)

**What to build:** 計時器頁的畫面更新迴圈每一幀都對每張卡片重算顯示值、格式化文字和檢查提醒，即使所有計時器都閒置或暫停。在 OBS 裡這個頁面會一直開著，是持續的 CPU 負擔。改成每幀先用便宜的方式判斷「顯示會不會變」，會變才做完整更新。畫面更新仍由 `requestAnimationFrame` 驅動（OBS Browser Source 以它的幀率驅動 rAF），不要改用 setInterval，也不要停掉迴圈再靠事件喚醒（漏掉喚醒條件會讓畫面卡住）。

來源：效能審查（2026-11-15），計時器第 1 項，方案 (a)。

- [x] 所有計時器閒置或暫停、也沒有提醒效果時，每幀不再逐張卡片做完整的計算
- [x] 計時器在跑時，顯示的秒數（以及開啟「顯示小數」時的小數）照常即時更新，不延遲、不跳秒
- [x] 目標時間型的計時器、時間到的轉換、提醒效果的開始與結束都照常顯示
- [x] 從暫停或閒置狀態開始、重置、切換模式後，畫面立刻更新
- [x] 有測試涵蓋「該更新時一定會更新」的情況

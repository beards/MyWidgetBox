# 02: 骰子拖動設定時只重畫有變的區塊

Status: resolved
Blocked by: None (can start immediately)

**What to build:** 骰子頁在每次狀態變動時都整頁重畫，拖動拉桿或選顏色時每個 input 事件都會：重新指定絨布背景（一個好幾百 KB 的 data URL）、重建骰組列表、重建歷史紀錄、更新分享面板。改成每個區塊記住上次用的資料，沒變就跳過。

來源：效能審查（2026-11-15），骰子第 1、2 項。

- [x] 拖動與骰組、歷史、背景無關的設定時，骰組列表與歷史紀錄不重建，絨布背景不重新指定
- [x] 絨布顏色、背景種類改變時，背景照常更新；從其他背景切回絨布、或從絨布切走時都正確
- [x] 骰組、歷史紀錄、分享連結在各自的資料改變時照常更新
- [x] 被拒絕的輸入（例如骰子數量超出範圍）仍會彈回正確的值
- [x] 語言切換後所有文字仍正確

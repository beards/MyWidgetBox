# 02: 完整骰組（多種骰、多顆、修正值、歷史）

**What to build:** 骰子支援 d4、d6、d8、d10、d12、d20、d100，可一次擲多顆並混合種類，可加減固定修正值。以組合式介面建立骰組（加入 N 顆某種骰、設定修正值），不做表達式輸入。結果顯示總和與明細（例如 `17 = 12 + 3 + 2`），控制介面顯示最近 20 筆 Outcome（只在記憶體）。預設骰組仍為 1d6。

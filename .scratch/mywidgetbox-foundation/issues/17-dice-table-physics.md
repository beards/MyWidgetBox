# 17: 骰子擲到桌上滾動的物理動畫

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 取代目前「原地懸浮空轉」的 3D 動畫：骰子從畫面邊緣被擲到桌面上，彈跳、碰撞、滾動後自然停下，停下時朝上的面就是 controller 事先決定的 Outcome。做法見 ADR-0003：先在畫面外以 cannon-es 完整模擬並記錄軌跡，依停下時朝上的面重新對應各面標籤，再播放軌跡。

- [ ] 物理引擎用 cannon-es（ADR-0002 允許骰子獨立加依賴）；模擬與面對應邏輯可在無 DOM／無 WebGL 下測試
- [ ] 每次從隨機一側邊緣擲入，帶隨機速度與旋轉；畫面四周隱形牆，骰子不會出界；骰子之間會碰撞
- [ ] 鏡頭斜上方約 45–60°，停下後不移動
- [ ] 一般模式有可見桌面，顏色可在外觀設定調整，並提供幾個質感預設（例如木紋、絨布）；透明背景時桌面隱形、只保留骰子陰影
- [ ] 停下後骰子留在原地；朝上面短暫高亮或浮出點數；總和與明細照舊
- [ ] 所有骰種（d4/d6/d8/d10/d12/d20/d100）停下時朝上面（d4 依其讀數慣例）與 Outcome 一致，含多顆、20 顆以上
- [ ] 「動畫長度」設定改為調整擲力與摩擦，使總時長大約落在設定值附近；超過上限時以阻尼收尾
- [ ] reduced-motion 維持快速呈現；「永遠完整動畫」覆寫仍有效
- [ ] 碰撞聲依撞擊力道播放（桌面／牆／骰子互撞），音量與力道成正比並限制同時播放數；沿用共用音效模組與設定
- [ ] 外觀新增欄位不需版本升級（缺欄補預設），舊 Share link 仍可開啟（凍結連結測試）
- [ ] WebGL 不可用時仍走既有 fallback
- [ ] 測試：給定 Outcome 與亂數種子，模擬 + 面對應後每顆骰朝上面等於 Outcome；模擬在步數上限內停止；Settings 往返
- [ ] 在 OBS 中流暢運作（needs manual verification）
